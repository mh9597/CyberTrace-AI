🔍 Root Cause Analysis & Defect Remediation

1. Array vs Key Mismatch in can() Helper

Category: Application Logic Bug (Resolved)
Root Cause: Frontend components passed permission arrays directly (PERMISSIONS.CREATE_COMPLAINT), but can() assumed string keys, causing valid permissions to evaluate to undefined.

Resolution: Upgraded can() in permissions.js to handle both arrays and string keys transparently.

2. SQLite Multi-threaded In-Memory Isolation

Category: Test Environment Concurrency (Resolved)
Root Cause: FastAPI background worker threads created isolated connections to sqlite:///:memory: without shared tables.

Resolution: Implemented StaticPool and check_same_thread=False in conftest.py.

3. E2E Selector Calibration

Category: Automation Test Calibration (Resolved)
Root Cause: Scripts looked for legacy aside drawer and assumed title was Transaction Network rather than Syndicate Money Flow Engine.

Resolution: Calibrated Playwright locators to match the active responsive top header and page DOM.
